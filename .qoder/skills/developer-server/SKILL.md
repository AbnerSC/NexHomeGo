服务器信息：
```
IP：172.17.1.220
账号：root
SSH端口：22
SSH别名：dev220
```
登录统一使用别名 `dev220`（本机 `~/.ssh/config` 已配置 Host dev220 → root@172.17.1.220:22，
密钥 `~/.ssh/id_ed25519` 免密，已验证可用）：
```
ssh dev220                           # 登录
ssh dev220 "命令"                    # 远端执行
scp file.txt dev220:/data/nexhome/   # 传文件
```
若在未配置该别名的新环境，回退方式为 `ssh root@172.17.1.220`（同一密钥）；
一旦配置别名，所有地方统一改为 `ssh dev220`。

当用户发出需要部署测试的请求时，可以使用此服务器进行无限制的测试。
为了不影响开发服务器其他服务，测试时使用目录 `/data/nexhome` ，
如果目录已有文件，允许强制删除清空；
注意检测服务器监听端口，不要发生冲突；
每次测试完成后，需要等用户确认完成测试回执，
彻底完成测试后，必须清理测试痕迹，包括停止服务和删除文件。
